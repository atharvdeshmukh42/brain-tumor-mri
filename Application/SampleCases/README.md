# BraTS 2021 sample cases

This delivery includes `BraTS2021_00495` and `BraTS2021_00621` from the BraTS 2021 training dataset. Each case contains FLAIR, T1, T1ce, T2, and the provided reference segmentation (`seg`). The sample loader uses the original BraTS case IDs and does not require other training cases.

Data attribution: U. Baid, S. Ghodasara, S. Mohan, et al. (2023), *The RSNA-ASNR-MICCAI BraTS 2021 Benchmark on Brain Tumor Segmentation*, The Cancer Imaging Archive. See the [full dataset citation and credits](https://doi.org/10.7937/JC8X-9874) and the [CC BY 4.0 license](https://creativecommons.org/licenses/by/4.0/). The training notebook retrieves the collection via the [BraTS 2021 Task 1 Kaggle mirror](https://www.kaggle.com/datasets/dschettler8845/brats-2021-task1).
